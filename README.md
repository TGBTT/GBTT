# Golden Bay Team Training (GBTT)

React website for Tom’s group fitness classes at Rec Park Centre, Tākaka — plus interactive **Studio Flow** and **Class Board** demos.

## Develop

```bash
npm install
npm run icons
npm run dev
```

Fitness demos:

```bash
cd sim-demos
npm install
npm run dev
```

## Build

```bash
npm run build:all
```

For GitHub Pages project URL, build marketing with `VITE_BASE=/GBTT/`.

## Contact backend

See [`google-apps-script/README.md`](google-apps-script/README.md). Set `VITE_FORM_ENDPOINT` when the web app is deployed.
